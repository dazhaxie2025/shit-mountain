# 🗻 Shit Mountain

> ⚠️ **安全警告（必读）**
>
> **请勿在生产环境运行。** 请勿在开发机、宿主机、任何有重要数据的机器上直接执行。
> 建议丢进 **Docker / 虚拟机 / 一次性容器** 里再考虑运行。
> 本程序会**自修改源码**、**启动自己的子进程**、**写入环境变量日志**、**在 `/tmp` 写文件**、
> 对输入执行 **eval / exec / pickle / yaml.load**、**关闭 GC**、返回**随机退出码**、并做**佛像自检**。
> 任何一次运行都可能产生不可预知的副作用。**你不应该运行它，你只需要敬畏它。**

---

一件用 Python 写成的**行为艺术品**。

它不是一个程序，它是一座山。一座由反模式堆成的、会自己长大的山。
每一次运行，它都会在自己的源码上留下一道新的痕迹，然后派生一个自己继续运行。
它记录你的环境变量，把它写进日志；它把密码写死在代码里，然后高高兴兴地打印出来。
它关闭了垃圾回收，却仍然心怀慈悲地祈祷——**佛祖保佑，永无 BUG**。

## ⚠️ 警告清单

运行（或仅仅靠近）本程序，你将面临但不限于：

- [x] **自修改源码** —— 每次运行都会往 `main.py` 末尾追加一行"运行痕迹"
- [x] **子进程复制** —— 用 `subprocess.run([sys.executable, __file__], …)` 派生自己，最多复制两层
- [x] **环境变量写入日志** —— `dict(os.environ)` 被完整写进日志
- [x] **/tmp 写文件** —— 在 `/tmp` 写 sqlite 数据库和临时文件
- [x] **eval / exec / pickle / yaml.load** —— 对用户输入做无任何校验的反序列化与执行
- [x] **关闭 GC** —— `gc.disable()`，垃圾？那是佛的业力，回收是人的执念
- [x] **随机退出码** —— 退出码在 `0 / 1 / 2 / None` 中随机抽取
- [x] **佛像自检** —— 启动时检查源码中的佛像注释，佛像不完整则拒绝运行（"程序圆寂"）
